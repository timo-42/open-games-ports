# Subsystem analysis: fx and animation (cod2_lnxded 1.3)

Target: `cod2_lnxded`, SHA-256 `05e774a3ee9fb487d4ec8a3d7d8d8e667f8ae459653e3c9e60a1c55604d5a3a7` (ELF32 i386, GCC 3.3.x C++ ABI).
Scope: effects system (`Effect`/`Particle`/... classes, `.efx` templates, config-tree text parser), XAnim (anim clips, node trees, blend slots), XModel / XModelParts, DObj (model+skeleton instances), anim-tree script parsing (`animtrees/*.atr`), BG player animscript, server-side model and skeleton glue.
Companion file: `fx-anim.structs.json` (canonical struct layouts and per-struct conflicts).

Evidence tags: **[O]** observed (disassembly, string, readable pseudocode, typeinfo/vtable bytes), **[I]** inferred (structure, callers, lineage), **[U]** unknown. Lineage (id Tech 3 / IW) is used for naming hints only.

* Functions selected from `analysis/symbols/symbols.json` by tags `fx`, `xanim`, `xmodel`, `model`, `anim`, plus `client/fx`, `common/dobj`, `game/dobj`, `server/model`, `server/skel`, `bg/animscript`, `player/animation`, `mp/anim`, `mantle/anim`, `collision/static-model`, `entity/area-effect`, `configstring/model`, `config/tree` and the `XAnim_*` helpers tagged `math/vec`: **927 functions** (902 tagged + 25 `XAnim_Vec*`/`DequantVec4` helpers). Chunks used: 004, 007, 009, 020, 031-035, 039, 040, 052, 054-059 (all in `chunks_done` except 033, see below). [O]
* Chunk 033 (`0x080c03d8..0x080c3b90`, XAnim tree/slot/pose API, 88 functions) is **not** in `chunks_done`, and `recon/chunks/chunk_033*` is untracked (being rewritten by another lane) but `analysis/symbols/chunk_033.json` is complete (88 translated) and merged into `symbols.json`. It is used here as provisional evidence; its layouts were cross-checked against chunk 032 and against the disassembly (section 8). ## 1. Purpose and architecture

### 1.1 What this code is in a dedicated server

The dedicated binary statically contains the **whole effects system of the client** (templates, parser, particle/emitter classes, scheduler, draw sort, frustum code) and the whole **XAnim/XModel/DObj stack**. They are used very differently: [O]/[I]

| --- | --- | --- |
| XModel loading (`xmodel/`, `xmodelparts/`), asset tables, default model fallback | **Live.** Models are loaded for `G_ModelIndex`, static `misc_model`s, DObjs and effect `models` keys. | `SV_ValidateModelName` 0x08091e48 -> `XModel_FindOrLoad` 0x080c5840; `cm_static_model_load_handle` 0x08058170; `Model_RegisterByName` 0x08131530. [O] |
| DObj (model instance + skeleton cache), server DObj handle table | **Live.** Created per entity with a model, used for tags, hit boxes, bone controllers, traces. | `Com_ServerDObjCreate` 0x08062d8e <- `Ent_RefreshAttachments`, `Game_FreeAllEntities`; `DObj_Traceline` <- `SV_ClipMoveToEntity_Line`. [O] |
| XAnim trees, blend slots, notifies, `animtrees/*.atr` parser | **Live.** Server drives anim trees so script `notify` events (anim "end", key notifies) and bone poses (tags, hit boxes) are correct. | `PlayerAnim_UpdateTree` <- `ClientEndFrame`; `XAnim_*` slot/blend API; `Scr_LoadAnimTree` -> `Anim_*`; notifies via `Scr_RunNestedCall` (0x080be3a0 area). [O] |
| BG player animscript (`mp/playeranim.script`) | **Live** (shared `bg_*` code used by pmove). | `BG_AnimParseAnimScript` via `Player_LoadMultiplayerAnims`; `BG_AnimScriptEvent` <- `PM_*`. [O] |
| FX **template** loading (`fx/<name>.efx`) | **Live, but only when `dedicated != 0`** (`com_dedicated` @0x084a8780). Used to validate effects, get `misc/missing_fx`, and compute effect durations. | `SV_SpawnServer` 0x08093520 (chunk 021 lines 779-836). [O] |

So a port of "fx" for this server needs the `.efx` loader, the config-tree parser, the template structs and the duration query; it does **not** need the particle simulation to be bit-exact to be server-correct. A client port would need the rest (documented here for completeness).

## 2. Entry points and call flow (server-live paths)

### 2.1 Startup / map load

1. `Com_Init_Try_Block_Function` 0x080620c0 calls `FxPool_Init` 0x081240d8 (stamps the `-1` "unused" marker in all 64 blocks of the 2 MiB effects pool at 0x08853380), `DObj_InitGlobals` 0x080b94c0 (interns the 17-byte all-zero duplicate-part table into `g_085bc828`) and `XAnim_InitSlotPool` 0x080bc6c4 (builds the 4096-slot ring at 0x085bc900, interns the string `"end"`, sets debug-name flag `g_085e4f24 = com_developer->value_08 != 0`). Static initialisers (`__static_initialization_and_destruction_0` 0x0812926a via `_GLOBAL__I_FxPools` 0x081299ac) construct the ten pool descriptors at 0x08a53388..0x08a533d0. [O]
2. `Com_InitDObj` 0x08062ed4 (via `Com_Restart_Subsystems`) resets the DObj slot tables (0x7ff slots). [O]
3. `SV_SpawnServer` 0x08093520: after the BSP is loaded and sound aliases (`Com_LoadSoundAliases`) are set, if `com_dedicated != 0`: `Fx_Wrap_08133780(0)` (= `FX_Init(0)`), then `FX_LoadMissingEffect()` 0x0812c34c; then three warm-up `SV_RunGameFrame` calls. On map change/shutdown with `com_dedicated != 0`: `Fx_Shutdown_Wrap1()` (= `FX_ShutdownSystem(1)`) at lines 780 and 1012. [O]
4. `FX_Init(flag)` 0x08133780: per-context init (context = `Net_CurrentClientNum()`, 0 on the server), `FX_ShutdownSystem(1)`, `g_fxRequireMaterials(0x08188ab0) = flag` (server passes 0, so `shaders` keys are ignored), allocates the 0xc-byte `FxScheduler` (`Fx_AllocSmall` = `Com_MallocZeroed(0xc)`), publishes it in `g_08a53804` and `g_08a533f0[ctx]`, `FX_ResetTemplateCount()`, `FX_ClockReset(g_08188ac0)`. [O]
5. `FX_LoadMissingEffect` loads `misc/missing_fx`; on failure `Com_Error(1, "^1ERROR: could not load default effect file '%s'")` (map load aborts). [O]
6. `SV_InitMapState` 0x080925e6 calls `FX_ResetBlockers` (sets blocker count 0x08a53cb0 = 0). [O]

### 2.2 Effect template lookup

`FX_GetEffectByName(name)` 0x0812c38a: strips one leading `/` or `\`; requires case-insensitive prefix `"fx/"` (else prints `Effect file '%s' must start with fx/.` and returns the missing-effect template); copies the remainder (`FX_CopyEffectName`, 0x58-byte buffer) and calls `FX_LoadTemplate` 0x0812bc12 (registry lookup by `strcmp`, else `FX_BuildTemplate`, then `FX_RegisterTemplate`; the registry holds 0x100 templates, overflow prints `^1Max effect templates of '%i' exceeded` and returns 0). Failure returns `g_fxMissingTemplate` (0x08a53808). [O]

`FX_BuildTemplate` 0x0812c4f2: `FX_LoadEffectFile` -> `sprintf(path,"fx/%s.efx")`, `FSH_FOpenFile`, read into temp memory, NUL-terminate, `ConfigTree_Parse`; on missing file `Effect file load failed: %s: file not found`. Then iterate children of the root block (`FX_ParseNodeChild(FX_ParseNodeSelf(root))`), match block name case-insensitively against the 12 segment type names; unknown names are skipped (index still increments). Per recognised block: `FX_Alloc(0x2a4)` (zeroed hunk alloc tag 4), `FX_PrimSetDefaults`, `type`, `index`, `PrimitiveTemplate::Parse` (0x081314a0 -> `ParseKeys` 0x08130248), `FX_PrimValidate`, `FX_TemplateAddPrim` (max 0x18 prims, else `FxScheduler:  Error--too many primitives in an effect`). Any parse/validate failure releases the prim lists and returns 0 (-> missing_fx fallback). [O]

Segment type names, in order (`type = index+1`): `particle`(1) `line`(2) `tail`(3) `cylinder`(4) `emitter`(5) `decal`(6) `orientedparticle`(7) `fxrunner`(8) `light`(9) `cameraShake`(10) `flash`(11) `cloud`(12). Types 1, 3 and 7 require materials **only if** `g_fxRequireMaterials != 0` (`^1FX Error, no materials defined for primitive template of type '%i'`). Types 6, 8, 10 have no object class in the pools (handled by `Fx_QueueEvent*`; **[I]** decal/fxrunner/cameraShake). [O] names and validation, [I] class mapping.

## 3. FX data formats

### 3.1 `.efx` text (read by `ConfigTree_Parse`)

The text is a nested block/attribute format parsed by the config tree (section 3.2): root block `"Top Level"` -> one child block per primitive (`particle { ... }`), attributes `key value...` and nested blocks for channel groups. Keys are matched case-insensitively. [O]

Primitive keys (dispatcher 0x08130248, `PrimitiveTemplate::ParseKeys`): `count`, `shaders|shader`, `models|model`, `impactfx`, `deathfx`, `emitfx`, `playfx`, `life`, `cullrange`, `spawnRange`, `delay`, `bounce|intensity`, `min`, `max`, `angle|angles`, `angleDelta`, `velocity|vel`, `acceleration|accel`, `gravity`, `density`, `variance`, `origin`, `origin2`, `radius`, `height`, `wind`, `rotation`, `rotationDelta`, `flags|flag`, `spawnFlags|spawnFlag`, `nonUniformScale`, `useLength`, `name`, `shaderImpact`, `sequenceStartFrameMode`, `sequenceFixedFrameValue`, `sequencePlayRateMode`, `sequenceFixedFpsValue`, `sequenceLoopMode`, `sequenceLoopTimes`, `spawnFrustumCullRadius`. Unknown key: `Unknown key parsing an effect primitive: %s`; any failing key: `^1FX Error while parsing key '%s'`. After keys: `min/max` bounding box must satisfy `max >= min` per axis and `(max.z-min.z) >= (max.x-min.x)` and `>= (max.y-min.y)`, else `^1FX bounding box mins / maxs invalid ...` / `... width or depth is larger than height ...`. [O]

Channel groups (child blocks), mapped by `g_fxGroupKeys` to a channel index 0..23: `rgb`0, `rgb2`1, `rgbRand`1, `alpha`2, `alphaRand`3, `size|width`4, `sizeRand`5, `size2|width2`6, `size2Rand`7, `length|height`8, `lengthRand`9, `rotationDelta`10, `rotationDeltaRand`11, `velocityX/Y/Z`12-14, `velocityXRand/YRand/ZRand`15-17, `velocity2X/Y/Z`18-20, `velocity2XRand/YRand/ZRand`21-23. Inside a channel: `curve`, `scale`, `start`, `end`, `parm|parms`, `flags|flag` (`Unknown key parsing a channel: %s`). Vec3 channels 0/1 use `"%f %f %f %f"` points (time + rgb), scalar channels `"%f %f"`. After parsing, `FX_PrimBuildCurves` 0x0812daac + `FX_BuildEnvelopeCurve/CurveRatio/CurveRate` build sample tables (`fn_08123f3c` returns the key-table handle stored in the template). The curve sample builder `fn_08123b5e` and handle allocator live in chunk 053 (unfinished). [O] keys/strings, [I] channel semantic names.

Flag tables: `g_0815fae0[0x18]` (prim `flags`: includes `depthHack`, `setShaderTime`, ..., `useRandomVelocity`=0x80000 set automatically by `velocity` when lo!=hi, `useRandomVelocity2`=0x100000 by `acceleration`) and `g_0815fcc0[0xd]` (`spawnFlags`: `org2fromTrace`, ...). The full names are in `.rodata` (not transcribed here). `impactfx` ORs 0x820 into flags, `deathfx` 0x200, `emitfx` 0x100; `playfx` leaves flags unchanged. [O] ORs; table contents [U].

Sequence keys: `sequenceStartFrameMode` accepts 0..2, `sequencePlayRateMode` 0..1, `sequenceLoopMode` 0..1, `sequenceFixedFrameValue` succeeds if > 0, `sequenceFixedFpsValue`/`sequenceLoopTimes` succeed if >= 0, `spawnFrustumCullRadius` stores only if >= 0. [O]

`models|model` values must satisfy `String_IsXModelPath` (prefix `models/`); `Model_RegisterByName` strips 7 chars and calls `XModel_FindOrLoad(name+7, Fx_AllocCallback, Fx_AllocCallback)` (hunk allocator), so **an effect that names a model forces that xmodel to load into the hunk**; failure prints `PrimitiveTemplate::ParseModels, could not register model '%s'` and fails the prim. `ParseModels` pushes the model pointers into the **same** pointer list as materials (`+0x68`). `shaders` keys: `Material_RegisterStub` returns 0 and is only invoked when `g_fxRequireMaterials != 0`. `impactfx/deathfx/emitfx/playfx` call `FX_GetEffectByName` recursively (missing -> `FxTemplate: ... effect file not found.`; recursion into the registry means effect load order affects registry order). [O]

### 3.2 Config tree (`ConfigTree`, `ConfigBlock`, `ConfigAttr`, `ConfigValue`)

Generic brace text tokenizer/tree used by the effect parser (chunk 058, 0x08131ee2-0x0813340x, tagged `config/tree` and `fx/parser`). Layouts in the structs file. Root block is named `"Top Level"` (rodata 0x08160640). Blocks keep an insertion-order list and a case-insensitive sorted list (`sortNext/sortPrev`). `ConfigTree_Parse` creates a 0x2800 string pool on demand. Accessors named `FX_ParseNode*`/`ParseNode_*` in chunks 056/057 are in fact ConfigTree field readers (naming problems, section 10). [O]

### 3.3 Template objects

`fx_template` (0x68 bytes): `{char *name; int primCount (<=0x18); prim *prims[24]}`; `PrimitiveTemplate` (0x2a4 bytes) layout in the structs file (reconciled from chunks 055/056/057/058). Registry `g_fxTemplates[0x100]` at 0x08a53400, count at 0x08a53800, missing template at 0x08a53808. [O]

### 4.2 Effect lifecycle ([O] from chunks 054/058, with caveats)

`FxSpawner_Spawn`-style functions allocate from a pool, run the base constructor, then `FxSpawner_Setup` 0x081355be: reserve a slot in **list A** if the spawner handle is valid (bound to an entity/bolt) else **list B** (arrays at 0x08a63c00/0x08a65880, shared cap 0x708 effects); on overflow `FX_ListFull` (empty), returns 0 and the object is deleted via vtable +4. Otherwise: register origin ref (`FX_AddOriginRef`, entries within 131072 units are shared), copy `flags` from the prim, `startTime = now`, `endTime = now + FxRange_Random(prim.life)`, set `+0x34` template pointer, `+0x38` prim index, `+0x10` from prim `+0x98`, `+0x14/+0x20` (mins/maxs) from prim `+0xa0/+0xac`, `+0x30` death-fx pick from `+0x78`, `+0x2c` impact-fx pick from `+0x70`, call vtable `+0x20` Init, attach binding. `FxSpawner_Randomize` 0x08135956 then rolls per-flag random values and the spawn origin (`FxSpawner_ComputeOrigin` 0x08134d90: local offset from `origin` ranges, spherical spread if flags2 bit 1 using `radius`, cone/disc if bit 4, optional axis rebuild; `FxSpawner_ComputeTraceOrigin` 0x08135296 traces 16384 units along the axis if bit 8), `FxSpawner_SetupSequence` picks frame and rate, `FxSpawner_ApplyElapsed` advances by delay overshoot. [O]

Per frame `FX_UpdateListA/B` 0x0813482e/0x081348ee: effects past `endTime` (flag 0x400) or whose Update returns 0 are removed (swap-remove through `IntArray_SwapA/B`, deferred free of the tail), then `FX_CollectDrawListA/B` (hidden ones skipped), `FX_SortDrawList` 0x0813473c ranks origin-refs by distance and `qsort`s draw entries with `FX_CompareDrawEntries` (sortKey, origin-ref rank, sortKey2, far first); `FX_DrawEffects` 0x08134c80 draws (vtbl +0x14) and prints `Active    FX: %i`/`Drawn     FX: %i`/`Scheduled FX` when the debug cvar is set. In this build the renderer submit `FX_NoopA` is an empty function and `FX_ReturnZero*` stubs replace client queries (sound, cg time, collision tokens). `FX_GetBoneOrientation` is a stub that prints `FX_GetBoneOrientation called!` and returns 0 (0x08133756). [O]

Particle motion: velocity and acceleration are curve-driven (`EvalVelocityTotal` = velocity + acceleration + gravity terms + accumulated offset +0xc4); gravity is `(0,0, ms*gravity*0.001)`; with flag 0x20 each step does a world trace (`FX_InitSampleRecord` -> `Sweep_TraceBox*`), flag 0x400 kills on impact, 0x800 spawns the impact effect, otherwise `HandleImpact` reflects about the normal scaled by bounce (+0x100) or stops (`Particle_ShouldStop`: normal.z>0 and |v|^2<16, or trace fraction exactly 0). Trace mask comes from `g_08188ac0+0x80` clamped to <=5 when flag 0x2000000. [O]

Frame/clock object (`g_08188ac0` -> static 0x08a5c9e0, 0xfc bytes): `FX_ClockAdvance` clamps delta to 0..200 ms unless time is paused (`g_08a53c98->byte8`), copies the 28-int view state (+0x14..) to +0x84; `FX_ClockAdvanceFixedStep` steps in 200 ms slices calling `Fx_ProcessPendingEvents`, `FX_UpdateListB`, `FX_UpdateListA`. `FX_RandomStep` (+0xf4) is a multiplicative LCG `seed *= 0x0369d035`; **+0xf4 is also written with the current time by `FX_ClockAdvance`/`Reset`**, so the RNG is reseeded from the clock every advance (observed dual use). [O]

### 4.3 Pools and state

## 7. XAnim

### 7.1 Clip file format (`xanim/<name>`, version 0xe)

`XAnim_LoadParts` 0x080c3f8a (4768 bytes): `i16 version(14)`, `u16 numFrames`, `u16 numBones`, `u8 flags` (bit0 looping, bit1 hasDelta), `i16 frameRate`; optional delta track (two key lists: rotation then translation); `ceil(numBones/8)` bytes of **negate bits** then **2D-rotation bits** (the latter copied into the asset); `numBones` NUL-terminated bone names (interned as script strings, type 9); per bone a rotation key list then a translation key list; notifies. Frame counts: looping adds one frame; stored `numFrames` is `frames-1`; `frequency = frameRate/numFrames` (0 when numFrames = 0). Index tables are u8 when `numFrames < 0x101`, else u16 (static helpers `XAnim_ReadRotKeys/ReadTransKeys/AllocKeyTable` exist only inside `chunk_034.cpp`, they are inlined in the original function and have no addresses). Rotation keys are int16 quats (`XAnim_ReadQuat4/Quat2`, normalised by 32767), translations are floats; one-key lists store the value inline (`lastIndex == 0`). Errors: `^1ERROR: xanim '%s' not found / has 0 length / out of date (version %d, expecting %d)`. Notifies (`XAnim_LoadNotifies` 0x080c3e62): `u8 count`, entries `{NUL-terminated name (interned, type 3), u16 frame}` with `time = frame / numFrames` (0 when `numFrames == 0`), followed by an implicit `"end"` notify at time 1.0 (`numNotifies = count + 1`). [O] format fields; per-key encoding details beyond the above [I] (not fully traced).

`XAnim_FindOrLoad` 0x080bc986: asset-table lookup type 5 -> `XAnim_LoadParts`; failure prints `^3WARNING: Couldn't find xanim '%s', using default xanim '%s' instead` and clones the default xanim named `"void"` (`XAnim_CloneHandleTable`, marks `is_fallback`); `XAnim_Find` (0x080bc8b6) is the strict variant (`Cannot find xanim '%s'`). ### 7.2 Trees, nodes and blend slots

* A **node table** (`XAnim_AllocNodeTable`) = 0x0c header `{debug name*, nodeCount, debug names**}` + `nodeCount` 8-byte nodes (node k at `table+0x0c+8k`). Leaf (`childCount==0`): payload is the loaded xanim asset pointer (`XAnim_SetLeafNode`: `Cannot find xanim '%s'` on failure). Group: `{u16 modeFlags, u16 firstChild}`; `XAnim_SetGroupNode` writes the group's own index into every child's `aux` field (so `aux` = parent index for children, cached key index otherwise). Debug names exist only when `g_085e4f24` (developer). [O]
* An **XAnimTree** (per DObj) is `{nodeTable*, i16 entnum (= entity handle+1, 0 on client), u8 flag06, u8 flag07, u16 slotOfNode[n], u16 handles[n], u8 generation, u8 gen2[n]}`. `flag06 == 0` selects the time-based sampler (`XAnim_AccumulatePartMotion`) else the keyed delta sampler (`XAnim_ApplyKeyedPartDelta`); `flag07 == 0` uses the slot's `+0x20` weight in `XAnim_BlendNode` (chunk 033 calls it `oldWeight`) else the `+0x1c` weight. Note: chunk 033's `weight@0x1c`/`oldWeight@0x20` naming is inverted relative to section 7.2 slot fields; which of the two the flag07 branch really selects therefore depends on that rename ([I]). [O]
* **Blend slots**: global ring `g_085bc900[0x1000]` of 0x28-byte records, slot 0 is the sentinel/free-list head, list links 12-bit wrapped (`(i+0xfff)&0xfff`, `(i+1)&0xfff`). [O]
* Update path: `XAnim_AdvanceNodeCursor` 0x080beb06 (advance cursor by dt scaled by rate and clip length / weighted group length, wrap key index, propagate), `XAnim_UpdateBlendRecursive` 0x080bf112 (linear blend toward goal, reports active/conflict), `XAnim_FireKeysBetween` 0x080bf8d4 (fires notifies between cursor times; a completed cursor fires the node notify) -> `Scr_RunNestedCall(entnum-1, 0, stringHandle, 1)` so scripts receive `notify` on the entity; `XAnim_InsertPendingEntry` keeps the pending list `g_085e4920` (12-byte entries sorted by key time, **no capacity check**). ## 12. Behaviours a native port must reproduce

1. **Dedicated gating**: initialise the FX template layer only if `dedicated != 0`, after BSP/sound-alias load and before the 3 warm-up frames; run `FX_ShutdownSystem(1)` on shutdown/map change with the same condition; load `misc/missing_fx` and hard-error if absent.
2. **`.efx` loading rules**: path `fx/%s.efx`, name must start with `fx/` (case-insensitive), registry cap 0x100, max 24 prims, segment type table, unknown block names skipped but index still advanced, the key/flag/validation errors above, nested `impactfx/deathfx/emitfx/playfx` loads, model loads through the hunk, `shaders` ignored when materials are not required (server), bounding-box validation, missing-effect fallback template. Effect durations must equal `max(life.hi + delay.hi)` as float.
3. **XModel/XModelParts/xanim formats and errors** (versions 0x14/0x14/0x0e, path prefixes, 0x40 path buffer, 0x7f bone limit, default-model/default-xanim fallbacks with the exact messages, `models/` prefix stripping by `+7`). Dedicated: xmodelsurfs loading is a no-op returning the zero default.
4. **DObj semantics**: 8 model/0x7f bone limits, parent-bone resolution against earlier models only, **summed** bounds, lazily built duplicate-part table, 128-bit set/control/locked masks, generation-stamped skeleton cache with 0x40000-byte pool and the overflow warning, DObj slot allocation (1..0x7ff, `No free DObjs`), client/server handle maps.
5. **Anim notify delivery**: entnum stored in the tree as `handle+1`; notifies delivered through the script nested-call path with the exact "end" notify, ordering by the pending list sorted by key time; blend slot ring (4096, 12-bit wrap), goal/current weight math, rate handling, `loopsync/nonloopsync/complete` property flags and `void`/`void_loop` defaults in `.atr` parsing.
6. **BG animscript**: `mp/playeranim.script` grammar and limits, 64-bit condition masks, +50 ms duration rule, blend defaults.
7. **Floating-point details** that affect results: x87 `long double` returns (`XAnim_NodeTime`, `XAnim_NodeDurationSec`, vec helpers), chop-rounding `fistp` in `XAnim_MakeFrameKey`/`LocateKey*` (control word 0xc00) versus round-to-nearest in `XAnim_NodeDurationMs`, the `0x5f3759df` reciprocal square root with one Newton step, `1/32767` dequantisation constant `0x38000100`, `DObj_SetBoneTransform` half-angle `pi/360`.
8. **FX runtime, if a client/replay mode is ever added**: pool and list caps (0x708 effects, 64 x 0x8000 pool), the RNG reseed-from-clock, clock clamp (0..200 ms), fixed-step 200 ms loop quirks (compares `accumTime`), draw sort order, vtable slot semantics and serialisation type ids.

## 13. Inter-subsystem dependencies

* **Script (`script/*`)**: string table (`ScrStr_*` for bone names, notifies, duplicate tables), variable store for `.atr` trees (`ScrVar_*`), `Scr_RunNestedCall` for notifies, builtins `loadFx/playFx/...`.
* **Hunk/asset tables** (`Hunk_FindUserEntryByName`, `Hunk_AddUserEntry`, `Hunk_AllocAlign`, `Hunk_ReleaseEntriesInRange` which calls `XAnim_ReleaseHandleTable`, `XAnim_FreeNodeTableNames`, `XModelParts_ReleaseBoneNames`, `XModel_ReleaseSurfNames`).
* **Filesystem**: `FS_ReadFile` (xmodel/xanim/xmodelparts), `FSH_FOpenFile` + `FS_Read` + `FS_FCloseFile` (efx), `Com_Parse` family for `.atr`/animscript.
* **Collision/server world**: `XModel_GetContents`, `DObj_Traceline`, `cm_static_model_*`, area linking uses `DObj_GetBounds`; `Sweep_TraceBox*` used by FX motion (dead on server).
* **Game/pmove**: `BG_*` animscript, `PlayerAnim_*`, `PM_*`, `ClientEndFrame`, entity attachments (`Ent_RefreshAttachments`), `G_ModelIndex`, weapon defs (`projExplosionEffect`), configstrings (0x14e models, 0x34e effects, 0x24e anims `G_AnimIndex`).
* **Common/init**: `Com_Init_Try_Block_Function`, `Com_Restart_Subsystems`, `Com_ShutdownSubsystems`, `SV_SpawnServer`, `SV_Shutdown`, `SV_InitMapState`.
* **Memory**: `Com_MallocZeroed`/`Com_Free_A` (config tree, small FX allocations), `Hunk_AllocateTempMemory` (efx text, channel scratch 0x600 bytes).
